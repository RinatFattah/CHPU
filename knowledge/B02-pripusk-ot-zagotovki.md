# B02. Припуск от заготовки: есть ли что снимать

```
уровень:  🟩 НАШЕ (прогон 17_gib_ne_rezhem, замер на 12 деталях)
источник: раздел K15 в `.claude/CLAUDE.md`; термин в CAM — rest machining / WIP
шаги:     2, 10
вход:     грань детали, тело заготовки, пол стадии съёма объёма
выход:    припуск на грани, мм; обрабатывать её или нет
```

## Зачем блок

В нормативах припуск ВСЕГДА задан числом: «фрезеровать с припуском 0,5». Вопрос
«а есть ли на этой грани припуск вообще» ни один учебник корпуса не ставит. Для
гнутого листа он решающий: радиус гиба **уже согнут в заготовке**, и обрабатывать
его нечем и незачем.

## Правило

1. Припуск меряется **на самой поверхности**, а не по габариту грани. Габарит
   точен для плоскости и всегда засчитывает собственную высоту наклонной или
   кривой грани как припуск.
2. Грань тесселируется; над каждой точкой проверяется, стоит ли выше материал.
   Точка идёт в припуск, **только если она ВНЕ детали и ВНУТРИ заготовки**.
3. Выше пола стадии съёма объёма не считается — там уже снято.
4. Максимум по точкам меньше **0,05 мм** → грань готова в заготовке, операций не
   создаётся.

## Почему порог именно такой

Он стоит **в пустом промежутке, а не подобран**. На всех 12 фрезерных деталях
КнААЗ пропускается ровно одна грань — радиус гиба, 157–224 мм², припуск ровно
**0,00**; у каждой оставленной грани минимум **1,00 мм**, у одиннадцати из
двенадцати — 5 мм. Порог можно двигать от 0,01 до 1,0 без единой смены решения.

## Проверка (деталь 003)

| | |
|---|---|
| грань | внутренний радиус гиба R2,5, 157 мм² |
| центр дуги у детали | X 5,00 Z 5,00 |
| центр дуги у заготовки | X 5,00 Z 4,98 |
| припуск | 0,00 мм → операций нет |
| цена ошибки | 1 370 мм рабочего хода, 00:05:14 → 00:04:21 |

**Осторожно:** снятие обработки гиба само по себе оставляет полосу под обвод
контура нетронутой, и обвод начинает резать её боком. Блок B02 применяется
только вместе с очисткой полосы отдельной стадией.
