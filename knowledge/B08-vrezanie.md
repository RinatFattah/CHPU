# B08. Врезание и подход

```
уровень:  🟦 НОРМАТИВ
источник: Самарский ун-т «Режущий инструмент для станков с ЧПУ», с. 44–46;
          ОН-1980, карта 2, лист 1, п. 1.2
шаги:     12
вход:     класс фичи, есть ли предварительно просверленное отверстие,
          паспорт фрезы
выход:    способ входа в материал и его параметр
```

## Правило

> «Осевое врезание является **крайне неблагоприятным**, несмотря на рекламные
> материалы некоторых производителей.» — Самарский, с. 46

Допустимые входы, по убыванию предпочтительности:

| способ | когда | параметр |
|---|---|---|
| **с торца заготовки** | фича выходит на край | — |
| **винтом** | замкнутая зона шире ~2 Ø | шаг винта из паспорта фрезы |
| **рампой** | замкнутая зона уже 2 Ø, есть куда вести вдоль реза | **угол из паспорта фрезы** |
| отвесно | только по предварительно просверленному отверстию | — |

**Если отвесное врезание неизбежно** (осевая подача без готового отверстия),
ОН-1980 требует **двухзубую фрезу без центрового отверстия**: обычная фреза в
центре торца не режет.

## Что из этого у нас

`RAMP_ANGLE` = 20° — **константа, подобранная по времени цикла, а не взятая из
паспорта фрезы**. Замер на 003 (оценка по длине пути): 10° → 00:35:30,
20° → 00:29:59, 30° → 00:28:04. Путь врезания = глубина / tg(угла).

Расхождение с нормативом надо держать в виду: правильный источник угла — паспорт
`MT190VBE-012Z12R04`, а его у нас нет.

## Проверка (деталь 003)

Полка 2,5 мм, фреза Ø12, замкнутых зон нет — все входы идут рампой вдоль того
отрезка, который фреза и так сейчас режет. Отвесных врезаний в металл в программе
**0** (было 430 до доработки). Рампа не выходит за траекторию, поэтому зарезать ей
нечего — сверка 0/0 подтверждает.

**Ловушка:** вести рампу по ХОРДЕ дуги нельзя. На дуге R2 хорда уходит внутрь на
0,18 мм, а у внешнего контура внутри — тело детали.
