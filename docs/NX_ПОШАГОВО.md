# Симуляция уголка в NX 2406 — полностью с нуля

Станок: **sim01_mill_3ax_sinumerik**. Файлы в этой папке:
`sim_stock.step` (заготовка), `sim_part.step` (деталь), `program.mpf` (G-код).

Порядок: **сначала геометрия + WORKPIECE, потом станок.** WORKPIECE обязателен
сам по себе — без назначенных детали И заготовки стойка отвечает «No part and
blank geometry». А вот узлы PART/BLANK станка он НЕ заполняет: их назначают
руками в Фазе 3, в любом порядке сборки.

---

## Перед NX — сгенерировать программу и геометрию (терминал)

Три файла выше (заготовка, деталь, программа) не рисуются руками — их выдаёт пайплайн
из папки `ai_3d_pipeline`. Две команды, до захода в NX:

**1. Деталь + заготовка → управляющая программа и геометрия под симуляцию:**
```
python run_cam.py "<деталь>.stp" "out.gcode" --config config.yaml --stock "<заготовка>.stp" --nx-export
```
Строит траекторию по модели (черновая по этапам) → `out.gcode`. `--nx-export` дополнительно
кладёт рядом `out_part.step` (деталь) и `out_stock.step` (заготовку), пересчитанные в систему
координат G-кода — после авто-ориентации и переноса нуля. Их импортируешь в Фазе 1, и они
встают точно под траекторию. Имя `out.gcode` вторым аргументом задаёт общий префикс всех
выходных файлов.

**2. Программа в формат стойки (grbl → Sinumerik `.mpf`):**
```
python grbl_to_sinumerik.py "out.gcode" "out.mpf"
```
Срезает `(...)`-комментарии, включает живую смену инструмента `T1/M6`, убирает `G21` — без
этого симуляция Sinumerik не проходит. → `out.mpf`, его грузишь в Фазе 5.

Итог — три входа для NX: деталь `out_part.step`, заготовка `out_stock.step`, программа
`out.mpf`. В этой папке они лежат под именами `sim_part.step`, `sim_stock.step`, `program.mpf` —
переименуй в них или подставляй свои пути в фазах ниже.

## Фаза 0 — TO_INI.SPF (только Sinumerik; один раз)

**Для стойки TNC этой фазы нет** — текстовой таблицы инструментов у неё не
существует, `ToolChange.prg` читает номер через `FN 18: SYSREAD ID20`, а
геометрию берёт из кармана станка NX.


Файл сюда:
```
C:\Program Files\Siemens\NX2406\MACH\resource\library\machine\installed_machines\sim01_mill_3ax\cse_driver\sinumerik\subprog\TO_INI.SPF
```
Содержимое (наша фреза Ø12):
```
$TC_TP1[1]=1
$TC_TP2[1]="MILL_D12"
$TC_DP1[1,1]=120
$TC_DP2[1,1]=1
$TC_DP3[1,1]=75.0
$TC_DP6[1,1]=6.0
M17
```
Папка в Program Files → сохрани файл в другое место, потом скопируй сюда с правами админа.
Тип файла — «Все файлы» (чтобы не стало `.txt`).

## Фаза 1 — Новый файл с ОБОИМИ телами

1. Прошлые эксперименты (`sim_stock_step.prt`, `sim_part_step.prt`) закрой, можно не сохранять.
2. **Файл → Создать → Модель**, единицы **мм**, назови напр. `cam_sim.prt`.
3. **Файл → Импорт → STEP → `sim_stock.step`** → OK  *(заготовка)*.
4. **Файл → Импорт → STEP → `sim_part.step`** → OK  *(деталь; ляжет ровно внутрь заготовки — координаты совпадают)*.
5. Наведись на каждое тело → в строке состояния должно быть **«Твёрдое тело»**. Если «листовое» → **Вставить → Комбинировать → Сшить**.

Теперь в одном файле два тела: крупная **заготовка** (~90×80×45) и тонкий **уголок-деталь** (~77×40×21).

## Фаза 2 — Обработка: MCS и WORKPIECE

1. **Ctrl+Alt+M** → приложение **Обработка** → конфигурация **mill_planar**.
2. Навигатор операций → **вид геометрии** (кнопки-переключатели вверху навигатора) → 2× клик **MCS** → ноль оставь в **абсолютном (0, 0, 0), Z вверх** → OK.
3. 2× клик **WORKPIECE** (под MCS):
   - «**Задать деталь**» → кнопка выбора → кликни **тонкий уголок** → (1);
   - «**Задать заготовку**» → кликни **крупное тело** → (1);
   - OK.

*Отличить тела: заготовка крупнее/боксовее, деталь тоньше. Наведение показывает имя тела внизу.*

## Фаза 3 — Станок из библиотеки

**Исправлено 18.08.2026 по факту ручной работы Дениса.** Прежняя редакция этой
фазы описывала шаги, которых в диалоге нет, и обещала автоматическое заполнение
PART/BLANK, которого не происходит.

1. Навигатор операций → **вид станков** → 2× клик по станку →
   «**Вызвать станок из библиотеки**».
2. Класс **MACHINE → MILL** → станок под стойку ПРОГРАММЫ:
   `sim01_mill_3ax_sinumerik` для `.mpf`, `sim01_mill_3ax_tnc` для `.h` → OK.
3. В диалоге — **привязка системы координат**: выбрать
   «**Ориентировать ноль станка по абсолютной СКС**».
4. Дальше NX снова покажет то же окно, с которого начинали (где жали «Вызвать
   станок из библиотеки») → **ОК**. Не «Отмена»: отмена откатывает вызов.
5. Шагов «Добавить деталь обработки» → «Выбрать деталь» → привязка
   «Абсолютно» **НЕ существует** — не искать. Окна «Создать фиксированное
   сопряжение?» может не быть вовсе, это нормально.
6. **PART и BLANK назначить руками — ВСЕГДА.** Они не заполняются из WORKPIECE
   ни при каком порядке сборки, и это же записано в `guide.md`, Часть 6а п.4.
   **Навигатор станка** (иконка в боковой панели) → раскрыть до `SETUP` →
   на `PART` и на `BLANK` ПКМ → «**Изменить K-компонент**» → выбор геометрии →
   **PART = деталь, BLANK = заготовка** → ОК.
   Перекрытое станком тело берётся через **QuickPick**: навести, подождать
   секунду, клик, выбрать «Твёрдое тело».
7. Деталь «проваливается» в стол — косметика нашего нуля, на рез не влияет.
   Хочется красиво — «Сборки → Переместить компонент», сдвинуть по +ZM.

## Фаза 4 — Инструмент

1. Вид станков → раскрыть **[+] TOOL_MAGAZINE** → **кликнуть нужный карман**
   (`POCKET_01` для T1, `POCKET_02` для T2 …) и создавать инструмент уже в нём —
   тогда перетаскивать потом не придётся.
2. Вкладка Исходная → **Создать инструмент → MILL** → диаметр и длина реальной
   фрезы (у нас длина 75). Фреза со скруглённой нижней кромкой — задать
   **нижний радиус** (заводская `T01_D12R0.5FL20` это Ø12 R0.5; наши программы
   считаны под плоскую, там радиус 0).
3. Раскрыть секцию «**Номера**» → **Номер инструмента = номер T из программы**
   (регистры — тот же номер).

Класть инструмент напрямую в SPINDLE нельзя: драйвер смены берёт тело
**из кармана по номеру**.

## Фаза 5 — Запуск симуляции по коду

1. **Поиск (Ctrl+Space)** → «**Симуляция станка**» (или ПКМ по `NC_PROGRAM`).
2. Если «Операции не выбраны» — кнопка «Симуляция траектории ▼» →
   «**Симуляция внешней программы**».
3. Канал **Main** → кнопка папки → файл программы (фильтр файлов →
   «**Все файлы**», иначе `.h` не видно).
4. Открыть «**Настройки симуляции**» → раздел «**Удаление материала**» и
   поставить ЧЕТЫРЕ галочки:
   - удаление материала;
   - показывать ЗвПО;
   - скрыть геометрию детали при отображении ЗвПО;
   - скрыть геометрию заготовки при отображении ЗвПО.

   Без двух последних поверх ЗвПО остаются висеть исходные тела и съём не видно.
5. Там же группа «**Отобразить**» → меню «**Стационарный**» → выбрать
   «**Деталь**». Иначе едет стол, а не фреза: у `sim01_mill_3ax` подвижен стол
   (X/Y), шпиндель ходит только по Z. Относительное движение то же, но смотреть
   неудобно.
6. **Воспроизвести.**
   ✅ Заготовка перефасетится в голубой ЗвПО, фреза выгрызает её к форме детали.

## Фаза 6 — Сохранить результат

1. Не сбрасывая машину → лента, группа **ЗвПО** → «**Создать фасетное тело для ЗвПО**».
2. **Завершить симуляцию**.
3. **Файл → Экспорт → STEP** → протокол **AP242** → «Экспорт из: Выбранные объекты» → кликни фасетное тело → задай путь → OK. *(или STL)*

## Если на Фазе 5 всё равно «чушь» (не режет / не сходится)

Проверь по порядку:
- **BLANK = заготовка** (крупное тело), а не деталь/пусто — иначе резать нечего (частая причина).
- **TO_INI.SPF** на месте (Фаза 0) — только для Sinumerik; у стойки TNC таблицы
  инструментов нет вовсе, она берёт геометрию из кармана станка.
- В программе `T1`/`M6`; фреза в кармане, номер кармана = номер T.
- Ноль/крепление сошлись по Z.

Позиционирование/крепление — та самая «не всё чисто» зона из гайда Рината. Если после проверок не сходится — скинь Ринату скрин + «стол едет, деталь утоплена, съёма нет»: он это проходил и быстро скажет точный трюк.
