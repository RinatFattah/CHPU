# B05. Припуск под чистовую

```
уровень:  🟦 НОРМАТИВ
источник: ОН-1980 с. 6; ТПУ «Припуски», формула 5.6 и таблица с. 5
шаги:     8, 11
вход:     диаметр чистовой фрезы, шероховатость после черновой, длина детали,
          вид заготовки
выход:    величина припуска под чистовую, мм
```

## Предел по инструменту (ОН-1980, с. 6)

> Припуск, оставленный под чистовую обработку, не должен превышать
> **0,2–0,3 диаметра чистовой фрезы по глубине фрезерования и 0,2 диаметра по
> ширине**.

## Минимум по качеству (ТПУ, формула 5.6)

Односторонняя обработка плоской поверхности:

```
z_min = Rz(i−1) + T_деф(i−1) + ρ(i−1) + ε(i)
```

`Rz` — шероховатость после предыдущего перехода, `T_деф` — дефектный слой,
`ρ` — пространственные отклонения, `ε` — погрешность установки. Коробление:
`ρ_кор = Δк · ℓ`, удельная кривизна **Δк 0,02…10 мкм/мм** (0,02 — обработанная
получисто, 10 — необработанная горячекатаная; холоднокатаный прокат с учётом
транспортировки ≈ 5).

| переход | `Rz`, мкм | `h` (дефектный слой), мкм |
|---|---|---|
| фрезерование обдирочное | 80–150 | 80–100 |
| фрезерование чистовое | 20–50 | 40–60 |
| фрезерование тонкое | 3,2–6,3 | 10–30 |

## Проверка (деталь 003)

Припуск 0,5 мм при чистовой фрезе Ø12 — это **0,042 D**, вчетверо ниже верхнего
предела 0,2 D. Снизу: после черновой `Rz + h` = 160…250 мкм, то есть 0,16–0,25 мм;
на `ρ` и `ε` остаётся 0,25–0,34 мм.

**Открытый вопрос, который блок обязан показывать, а не прятать.** Заготовка —
гнутый лист длиной 90 мм. При Δк = 5 мкм/мм коробление даёт `ρ_кор` ≈ 0,45 мм и
съедает весь припуск. Либо Δк у гнутого катаного листа заметно меньше пяти, либо
заводские 0,5 мм тесноваты. **Проверяемо замером отклонения заготовки от
плоскости** — до замера 0,5 берётся с заводской программы, а не выводится.
